# StrainFM

Phase 0：研究领域界定与项目规范建立。

## 项目定位

本项目研究**细菌种内精细遗传多样性的基因组基础模型与评价方法**。技术起点是 Bacformer v3 的全基因组有序蛋白质上下文表示；核心目标不是复刻一个更小的 Bacformer，而是检验并改善跨物种模型对菌株级差异（核心基因等位变异、accessory genome、基因排列、移动遗传元件）的表征能力。

暂定英文方向：**Species-adaptive genome representation learning for fine-grained bacterial strain diversity**。Phase 1–2 只在**单一目标物种**内验证，不声称跨物种泛化；如需泛化，Phase 2 之后增加低成本第二物种复现。

## 核心研究问题

1. **表征缺口**：跨物种 Bacformer 在种内核心变异、可变基因和基因组组织上，保留了什么、遗漏了什么？
2. **物种适配**：目标物种继续预训练或专用监督，能否在未见菌株与独立来源上超过冻结模型和传统基线？
3. **数据效率**：新增基因组数量与新增种内多样性，哪个更能解释性能增益？
4. **评价有效性**：如何用独立标签、谱系感知划分和公平基线，避免循环论证与数据泄漏？

这些问题必须以预先定义的外部指标检验，不能只用 UMAP、聚类或预训练 loss 证明价值。

## 当前阶段（Phase 0）

- 确定导师指定的目标物种、研究用途与数据权限；
- 核验 `manifest_all.tsv` 的来源、权限、质量和可追溯版本；
- 建立数据审计、去重、独立划分和基线复现方案；
- 明确第一阶段的最小可证伪实验与 go/no-go 标准。

当前**未训练或运行任何模型**。材料中的论文结论、清单统计和工具状态是待核验输入，不是本项目实验结果。
