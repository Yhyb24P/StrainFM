# StrainFM 三阶段研究计划

更新：2026-11-05。三阶段主线与避免过度审计的原则来自用户本日明确指示（D0-14）；具体执行口径已完成一次同伴复核，记录见 DECISIONS。负责人：项目执行者。E. coli 候选的全量快照、元数据、去重/多样性和固定划分已完成并核验，正式目标物种仍待用户确认，尚无模型预处理或实验结果。当前交付见[候选数据报告](../data/results/escherichia_coli_data_preparation_20261105/README.md)。

项目研究跨物种细菌基因组基础模型在单一物种内部的菌株级表征能力，以及物种适配能否改善泛化。先完成数据与划分，再建立冻结表示基线，最后按基线证据决定是否继续预训练。第一轮聚焦种内遗传结构和未见菌株检索；表型预测、额外物种和架构改动不作为当前前置任务。

## 第一阶段：完成实际数据审计

**目的**：确定研究实际使用哪些基因组、包含多少独立样本、覆盖哪些种内差异，并形成固定的开发集与独立测试集。

1. **固定下载数据版本。** 对现有下载清单、实际 accession 与文件建立快照索引，记录来源、版本、路径、大小和内容哈希；后续补下载或替换产生新版本，不在同一版本中静默更新。复用已有清单哈希与抽样结果，对目标物种纳入文件完成必要的完整读取和内容指纹，不扩展到所有物种。
2. **确认目标物种与样本范围。** E. coli 保留为方法学试点候选；结合真实文件、质量、元数据和去重后多样性确认正式范围，不以原始记录数直接决定。最终物种由用户/导师确定。
3. **确认文件状态与元数据覆盖。** 区分清单记录、存在且非空、可解压、格式有效和质量合格；补齐实际文件 accession、BioSample/BioProject、组装级别和基本组装统计，汇总来源、时间字段的缺失率。记录排除原因，异常文件不反复补救阻塞整体推进。
4. **估计独立样本数量与种内多样性。** 合并同一 BioSample 的重复组装和精确序列副本，再用一种适宜的传统序列方法识别近克隆与谱系结构。分别报告文件数、去重后样本数、近克隆组数、谱系数和来源覆盖；这些是操作定义下的数量，不是统计独立性的绝对证明。谱系分辨率与近克隆阈值分别说明，不同时铺开多套分型工具。
5. **固定数据划分。** 开发集内部设训练/验证用途，独立测试集按近克隆组和可用来源信息留出。检查组间重叠、质量和多样性覆盖，再固定 accession、split、分组与随机种子。遗传距离/序列草图可用于本阶段去重和划分；注释、蛋白编码和模型输入处理在划分固定后开展。单样本统一规则可用于测试集，依赖多样本拟合的词表、归一化与特征选择只使用开发集。

**交付物**：目标物种的数据快照索引、可用性与元数据覆盖汇总、去重/多样性结果，以及固定的开发集和独立测试集清单。来源与权限管理按 [DATA_GOVERNANCE.md](DATA_GOVERNANCE.md) 执行。

**完成条件**：每个纳入样本对应实际文件与版本；能解释有效样本数、多样性和排除原因；划分有足够的参考候选与检索正例，并满足已选定的组间隔离规则。完成后进入第二阶段，不以补齐所有元数据或运行所有质量工具为条件。预训练重叠按可得清单检查，已知重叠排除出未见基因组评价池；无法核验的范围记为 unknown，单列结果并限制“未见菌株”结论，不无限等待完整预训练语料。

## 第二阶段：建立可信的表示学习基线

**目的**：在同一批基因组和固定划分上，判断原始 Bacformer 能否稳定恢复种内遗传结构，并对未见菌株进行有意义的检索。

1. **统一模型预处理。** 划分确定后，对同一批样本采用固定注释和蛋白排序规则，记录输入覆盖与截断。固定模型、蛋白编码器、软件版本、pooling 和推理设置，先做小批量输入正确性与吞吐检查，再提取全批表示。
2. **建立最小充分对照。** 比较冻结 Bacformer、其输入蛋白编码器的平均表示，以及第一阶段选定的传统序列方法。Base 配对 ESM-2，Large 配对 ESM-C；首轮选一种 Bacformer 配置。三者使用相同基因组；处理失败导致的样本差异必须说明。
3. **评价种内遗传结构。** 比较表示距离与传统遗传距离的一致性，按近缘/较远样本和谱系分层检查邻域保留。聚类图、ARI/NMI 可作辅助，不能单凭可视化宣称菌株分辨能力。序列派生标签适合本阶段结构诊断，结论限定为结构恢复，不扩写为表型或传播能力。
4. **评价未见菌株检索。** 固定 query、gallery、正例定义、k 和 ties 处理。可用开发集参考库评价测试查询；若严格谱系留出使其没有正例，则在留出谱系内预先固定 query/gallery，二者均不参与训练或调参。分别报告已见谱系中的新样本与未见谱系检索。
5. **判断稳定性与局限。** 在开发集检查重复推理、组装质量、截断与来源的影响；发现具体异常才增加对应诊断。是否进入第三阶段及适配方案选择以开发集结果为依据。独立测试集用于已冻结协议的确认性评价；若第二阶段已查看测试结果并据此调整方案，第三阶段另设确认性测试组，原测试结果保留为探索性证据。

**交付物**：匹配基因组的表示、传统距离/分组结果、固定检索协议、结构与检索指标表，以及是否进入第三阶段的判断。

**完成条件**：输入与评价可复现；能判断 Bacformer 相对匹配 ESM 均值和传统方法保留了什么、遗漏了什么；检索有明确分母、正例支持和按独立组计算的不确定性。Recall@k 与 Hit@k 分开报告；距离相关性作适当的描述，不把 partial Mantel 当作去混杂保证。

**进入适配的条件**：基线稳定、评价能区分方法，而且存在值得通过物种适配检验的改进空间。冻结模型不必先超过所有传统方法；若主要问题来自模态缺失、损坏输入或无法成立的评价，应先处理或收缩任务。原始模型已足够好、或没有可检验的适配空间，也可停止该路线。

## 第三阶段：验证物种适配价值

**目的**：检验物种专属继续预训练是否在控制数据和计算预算后改善泛化，以及新增基因组是否带来稳定收益。

1. **先比较一个适配方案。** 在第一阶段固定的训练范围内，以物种专属继续预训练对比冻结 Bacformer，使用相同预处理、评价样本和检索协议。开始前确认预训练目标及蛋白簇映射可复用；若需重定义目标，单独记录，不称为原目标的直接延续。
2. **控制数据和计算预算。** 继续预训练不使用验证/测试基因组。固定优化设置、最大计算预算和调参次数，记录处理 token 数、步数、实际 GPU-hours 和随机种子。冻结与适配模型共享评价及模型选择预算；冻结模型没有继续训练成本，单独报告适配的新增成本。
3. **开展数据规模实验。** 从去重后同一训练池设置少量嵌套规模点，固定验证/测试面板、采样规则和各规模适配计算上限，比较新增基因组后的独立测试表现。同步报告谱系/来源覆盖、质量、长度与重复暴露，区分数量增加、覆盖改善和训练时长增加；不预设必须达到 20k。
4. **按效应量判断价值。** 主要比较适配相对冻结模型的配对增益，另报相对传统基线的差距、置信区间与新增成本。预训练 loss 下降、开发集变好或某一次运行变好，均不足以证明泛化收益。多种子与重采样数量按数据和预算设定，在确认性评价前固定。

**交付物**：冻结/适配对照结果、数据规模曲线、计算成本记录和继续/停止建议；保留负面结果与失败项。

**完成条件**：能判断增益是否达到测试前确定的最小实用效应量、是否在独立测试集成立，以及更多基因组是否持续改善泛化。置信区间过宽时报告证据不足，不把“不显著”解释为“无效”。达到预算上限仍无实用增益时，停止该适配方案，不自动扩展架构、物种或训练规模。

## 执行边界与现有证据

审计限于影响样本纳入、身份合并、数据划分和结果解释的检查。已有结果可以复用；仅在输入变化、发现异常或关键判断尚未解决时重复检查。第一阶段不以药敏或其他独立表型标签作为必需条件。表型验证可在结构与检索主线成立后按用途增加，另定任务与范围。

- 四物种共 100 个抽样 FASTA 完整解压且格式有效，对应 NCBI 元数据已取回；抽样不能替代目标物种全体纳入文件检查。
