# StrainFM 研究计划（Phase 0 草案）

状态：2026-10-29 草案；待导师/用户确认目标物种、用途与数据权限，待同伴评审。
本文件定义研究领域、问题、假设、路线与阶段门槛。背景材料中的论文结论与数据统计已单独标注核验状态；未核验内容不当作既定事实。

## 0. 一页结论

- **值得做的方向**：不是缩小 Bacformer，而是研究“跨物种全基因组基础模型在单物种内部是否保留并利用菌株级差异”，以及物种适配能否带来可验证的增益。
- **最强创新点**：可证伪的**表征缺口诊断** + **物种适配** + **数据效率**三问，而不是一个新的网络模块。
- **当前最大风险**：把种内聚类当成菌株级能力；把构造标签当成外部验证；把预训练语料与测试集重叠当成泛化。
- **Phase 0 决策**：先审计数据、建立基线与独立评价，再决定是否继续预训练或改架构；在物种、用途和数据权限明确前，不启动训练。

## 1. 研究领域与边界

**暂定领域**：细菌种内精细遗传多样性的基因组基础模型与评价方法。

**英文方向**：Species-adaptive genome representation learning for fine-grained bacterial strain diversity。Phase 1–2 仅在单一目标物种内验证，不声称跨物种泛化；如需泛化，Phase 2 之后增加低成本第二物种复现。

**范围内**：
- 细菌基因组（以完整基因组和高质量组装为主）的菌株级表示学习；
- 核心基因等位变异、accessory genome、基因排列、移动遗传元件（质粒/岛）等信息来源；
- Bacformer、ESM-2/ESM-C 等蛋白质上下文表示；
- ANI、core-SNP、cgMLST、PopPUNK/PopPIPE、Panaroo 等传统基线；
- 谱系感知划分、跨来源泛化、数据效率、可复现评价。

**暂不在范围内**：
- 可操作的菌株构建方案、条件基因组生成、临床诊断/治疗决策；
- 噬菌体联合建模、复杂 DNA-蛋白质多模态预训练（除非任务证据表明必须）。

**研究对象**：细菌为主；清单中的病毒、古菌、真菌只用于统计与后续扩展记录，不进入当前主线。

## 2. 证据基线

### 2.1 已独立核验

- Bacformer v1 2025-07-20、v2 2025-08-13、v3 2026-08-19（bioRxiv API 记录；bioRxiv 页面曾显示 2026-08-17，两者差异需在引用时注明），同一 DOI `10.1101/2025.07.20.665723`。v1 的 60 页已通过 EPFL Infoscience accepted-version PDF 核实；v3 的 85 页未独立核实。均为 bioRxiv 预印本。
- v1 PDF（EPFL accepted version，pp. 30/32）：1,314,344 个 MAG、2,700,709,306 条蛋白质、24,663 个物种、70 个环境、48,932 个完整基因组、50,000 个蛋白簇、最大 6,000 个蛋白 token、15% 掩码；E. coli 7,585 株经 Leiden 得到 **6 个亚群**。v3 的精确计数应以 v3 Methods/补充材料复核；未复核前不改写为 v3 事实。
- 模型规模口径不一致：论文 backbone 为 26M/332M；Hugging Face checkpoint 总计 50.85M/431.77M（含 50,000 类蛋白质家族头）；官方 README 称 Large 为 300M；BacBench 表格写 27M（明显笔误）。做显存/算力估算时应以实际 checkpoint 为准。HF revisions：Large `84f85c37...`、Base `d1c461f1...`；README 2025-05-15 的 Large 权重 bug 通告需在缓存前核对。

- The DNA dialect（Veiner & Supek）确为 *Molecular Systems Biology* 2026;22(3):309–332，DOI `10.1038/s44320-025-00184-4`；其摘要支持“没有单一模型在所有任务占优，任务设计与预训练数据常比模型规模更重要”。

## 3. 研究问题与可证伪假设

| 编号 | 问题/假设 | 最小检验 | 支持判据 | 失败判据 |
|---|---|---|---|---|
| RQ1/H1 | 冻结的跨物种 Bacformer 表示保留种内谱系信号，但对近缘菌株的细微差异不足 | 按标签独立性分级：A1 为生物标签（暴发/传播配对、表型）；A2 为元数据（来源/时间）；B 级为 ANI/core-SNP/cgMLST/PopPUNK 等序列衍生谱系。比较 embedding 距离与遗传距离的相关性、Recall@k；与 ESM-2 mean pooling、k-mer/ANI 比较 | 在近缘菌株上显著低于传统基线，且误差集中在低 SNP 距离区间；A2 主要用于划分/泛化检验，需批次校正后才作辅助；B 级需用 partial Mantel 控制来源/批次 | 与 ANI/k-mer 相当或更好；无系统性缺口；或缺口只在 B 级出现而 A1 不支持 |
| RQ2a/H2a | 目标物种继续预训练/专用监督能在未见菌株和独立来源上超过**冻结 Bacformer** | 冻结 vs 继续预训练 vs 从零小模型；compute-matched（固定 GPU-hours 与超参预算）；预注册主指标 | 独立测试集 ΔM > 预设最小效应量，CI 不含 0 | ΔM 不显著或只在本源数据上提升 |
| RQ2b/H2b | 同一适配能超过**传统基线**（ANI/cgMLST/PopPUNK/Panaroo） | 与 H2a 同一划分；传统基线与嵌入+分类器分开比较；同等调参预算 | 在 A1 级或半独立任务上稳定超过基线 | 不能超过基线，或仅在 B 级构造标签上“超过” |
| RQ3/H3 | 在固定基因组数量下，增加谱系/来源多样性比随机增加数量更有效 | 随机采样 vs 多样性分层采样（按 PopPUNK 簇/来源组数操作化）；100/500/2k/5k/10k/20k 学习曲线；质量层与长度分布匹配 | 多样性臂的 ΔM 显著更大且可复现 | 两臂无差异，或数量效应主导；或去重后样本不足以支撑 20k 臂 |
| RQ4/H4 | 朴素随机划分高估泛化；需量化高估幅度 | 同一模型在随机划分 vs 谱系/来源留出划分上的差异；按克隆比例分层 | 量化出稳定的乐观偏差及与克隆比例的关系 | 无实质差异（此时作为评价校准步骤，不作为独立科学假设） |

**预注册要求（Phase 1 前）**：主任务、Recall@k 的 k 集合、ΔM 最小效应量、置信区间方法（按谱系/来源做 cluster bootstrap）、随机种子数、多重比较校正。H2a 与 H2b 分开报告；compute-matched 预算固定 GPU-hours 与超参搜索次数，非匹配上限结果另报；从零小模型只匹配适配预算、不匹配预训练算力，需在协议中注明。

**标签独立性**：A1 为生物标签（暴发/传播配对、表型）；A2 为元数据（来源/时间），主要用于划分与泛化检验，需批次校正后才可作辅助标签；B 级为序列衍生谱系（ANI/core-SNP/cgMLST/PopPUNK）。ANI/PopPUNK 同时是基线，不能用它们作为唯一金标准来证明模型“更好”；H1 主结论优先基于 A1，A2 只作辅助，B 级用 partial Mantel 控制来源/批次。若 A1 不足，需在评价协议中预定义降级为半独立任务的判据。

## 4. 候选物种与选择标准

| 物种 | 清单记录 | 优势 | 风险/限制 | 角色 |
|---|---:|---|---|---|
| Escherichia coli | 62,560 | 数据最多；Bacformer 论文已有种内分析；易复现 | 论文已重点使用，创新性压力大；近克隆与临床采样偏倚；含临床/致病分离株，仅做信息学分析 | **方法学试点首选** |
| Klebsiella pneumoniae | 44,401 | 临床与群体结构研究丰富；核心/可变基因组对比明显 | 临床分离株多；克隆暴发导致重复 | 主要候选，待数据权限确认 |
| Salmonella enterica | 27,252 | 血清型/谱系标签较丰富 | 病原体；采样偏倚 | 备选 |
| Staphylococcus aureus | 25,171 | 临床与 AMR 表型数据多 | 病原体；近克隆重复 | 备选（AMR 任务） |
| Acinetobacter baumannii | 18,891 | 医院流行克隆、泛基因组差异明显 | 病原体；数据质量参差 | 备选 |
| Pseudomonas aeruginosa | 17,579 | 基因组组织/功能研究基础好；适合 synteny | 病原体；慢性感染克隆 | 备选（synteny 方向） |
| Streptococcus pneumoniae | 13,200 | 血清型/重组研究丰富 | 病原体；重组使谱系定义复杂 | 备选 |

**选择标准**（按优先级）：
1. 导师/用户指定的物种与生物学问题；
2. 去重后独立基因组数量与完整基因组比例；
3. 种内多样性与独立来源（国家/研究/测序平台/时间）覆盖；
4. 可靠外部标签（cgMLST/PopPUNK/血清型/表型/暴发标签）；
5. 数据权限与临床数据属性；
6. 与 Bacformer 论文的重叠度与新颖性；
7. 传统基线与算力可行性。

**当前建议**：若导师未指定，先用 E. coli 做**方法学试点**（复现、数据审计、评价协议），但正式研究对象需在导师确认与数据权限明确后决定。注意：v1 的 E. coli 六群来自 MGnify MAG 子集（7,585 株），与本清单的 GCF/GCA 组装不是同一数据；两者重叠与注释差异需先检查。E. coli 记录含临床/致病分离株，涉及临床元数据时按数据治理处理。

若数据权限限制临床相关物种，低风险回退物种的清单规模不足：B. subtilis 1,402、L. lactis 633、Streptomyces 单物种约 100–200、C. glutamicum 92，无法支撑 20k 学习曲线与谱系留出。此时只能做小规模方法试点，或引入 AllTheBacteria 等外部来源并重新审计；H3 的规模必须相应缩小。物种、用途与数据权限应作为一个决策包提交用户/导师，而不是先选物种后补确认。

## 5. 研究路线

### Phase 0：领域界定与规范（当前）
- 确认物种、用途与数据权限；
- 完成清单审计（SHA-256、受控只读路径、元数据缺失率）、候选物种短名单、评价协议；
- 建立决策记录；完成规范与计划的评审。

### Phase 1：数据审计与基线
- 读取目标物种 FASTA（服务器权限确认后）；统一注释（Bakta）与质量分层；
- ANI/Mash 去重、PopPUNK/cgMLST 谱系、来源/时间/组装级别元数据；
- 提取 Bacformer 冻结表示；建立 ANI/k-mer/ESM-2/PopPUNK/Panaroo 基线；
- 检查预训练重叠；完成 H1/H4 的诊断。
- **门槛**：基线可复现；冻结 Bacformer 在 A1 级或半独立任务上达到预设的最低性能阈值（Phase 1 前写入评价协议），且在 B 级任务上与 ANI/k-mer 的差距不超过预设容忍度；否则最多进行 2 轮诊断（数据质量/截断/注释/重叠），仍不达标则停止或转向。不得复用 BacBench 已废弃的 strain clustering 旧划分。

### Phase 2：物种适配与消融
- 冻结 vs 继续 MPFP vs 等位变异/accessory 监督 vs 从零小模型；
- 受控消融：mean ESM、原始有序输入、打乱顺序（含距离匹配对照）、core-only、accessory-only、截断、注释流程、模型规模；
- 学习曲线：数量 vs 多样性；控制训练步数与数据质量。
- **门槛**：H2a 或 H2b、以及 H3 至少各有一个得到独立来源验证；否则停止/转向。H2a 与 H2b 分别报告，不以“超过冻结模型”代替“超过传统基线”。

### Phase 3：独立评价与交付
- 独立来源/时间留出；多种子与置信区间；失败案例分析；
- 形成论文/技术报告；明确负面结果与局限。

### 方向优先级
- **A 单物种上下文适配**：先做，成本最低，直接检验缺口。
- **B 核心/accessory/synteny 融合**：在 A 的诊断显示具体信息缺口后再做；三类配对诊断（核心近/可变远、可变近/核心远、两者均近）是核心实验。
- **C DNA/混合模态**：最后；只有任务确实依赖非编码/同义/调控信息，且 DNA 对照稳定优于蛋白上下文时才投入。

## 6. 评价体系

**任务类型**（按目标物种与标签确定）：
- 谱系/菌株检索：同一 cgMLST/PopPUNK 谱系的 Recall@k、距离相关性；
- 监督任务：来源预测、宿主关联、AMR 表型、暴发配对；
- 跨来源泛化：不同国家/研究/平台/时间留出；
- 数据效率：学习曲线与采样策略；
- 稳健性：组装质量、注释流程、截断、污染。

**基线**：距离型（ANI/Mash、core-SNP、cgMLST、PopPUNK/PopPIPE、Panaroo）与嵌入+分类器型（ESM-2 mean pooling、Bacformer 冻结、继续预训练、从零小模型）分开比较；监督任务需给 ESM-2/k-mer/Panaroo 特征同等调参预算的分类头。DNA 模型仅在任务需要时加入。

**划分**：谱系/克隆簇不相交；来源留出；时间留出；组装质量分层；去除近重复；检查预训练语料重叠。禁止在测试标签上调参。预训练重叠（1.3M MAGs + 48,932 complete genomes）需从**全部评价集**排除并报告比例，不只排除 test。ESM-2/UniRef 预训练污染无法排除，作为解释限制写入评价协议。

**指标**：距离相关性（Mantel/Spearman；B 级用 partial Mantel 控制来源/批次）、Recall@k（报告 k 集合与簇大小敏感性）、AUROC/AUPRC、校准、聚类稳定性、ARI/NMI（仅辅助）、配对 precision/recall。报告置信区间（按谱系/来源 cluster bootstrap）、多种子、效应量、多重比较校正；校准与不确定性单独报告。

**消融与负对照**：mean ESM、有序输入、打乱顺序（距离匹配/同 operon 内打乱）、contig 打乱、core-only/accessory-only、截断、Bakta vs 原注释、标签置换、随机输入、来源/批次混杂检查。

**统计**：Phase 1 前预注册主任务、主指标、k 集合、ΔM 最小效应量、CI 方法与种子数；嵌套交叉验证；测试集只用于最终评价；报告失败案例与按谱系/来源的分层误差；多重比较校正；B 级标签不得作为唯一证据。

## 7. 资源与可行性

- v1 报告：1.3M 基因组 embedding 使用 16 张 Intel Ponte Vecchio GPU 约 30 天（=480 GPU-天），产生约 5.6 TB 文件。按 480 GPU-天线性外推：62,560 个 E. coli 约 **22.9 GPU-天**（16 卡墙钟约 1.4 天）、约 266 GB；5,000 个试点约 **43.8 GPU-小时**（16 卡墙钟约 2.7 小时）、约 21 GB。**这是 GPU-hours 外推，不是实测**；实际取决于蛋白数、组装质量和编码器。
- 本机为 1×RTX 5090 D 32GB；`bakta`/`gtdbtk`/`checkm2`/`poppunk`/`chewBBACA`/`mash`/`fastANI` 当前未安装。20k 学习曲线臂在单卡上需按 GPU-hours 重新估算，不能直接沿用 16 卡外推。
- 基因组 Transformer 训练使用预计算 embedding，通常比全量蛋白 embedding 便宜；但需在试点上实测显存、吞吐和收敛。
- 显存/存储估算使用实际 checkpoint（Large 431.77M、Base 50.85M），不要只用论文 backbone 数字。
- 注释（Bakta）与去重是主要工程成本；先做 1,000–2,000 个高质量基因组的试点，再扩到全物种。
- 当前清单缺质量/来源元数据，FASTA 在远程路径；在权限和质量审计完成前，不能把 62,560 当作可用训练样本数。

## 8. 阶段门槛与交付

**Phase 0 gate**：
- 导师确认物种、用途与允许的数据范围；
- 清单 SHA-256 登记、受控只读路径、FASTA 可访问性确认；来源/时间/BioProject 元数据缺失率抽样审计；
- 候选物种短名单（含去重后数量与多样性估计）；
- 评价协议与主指标草案（含 A1/A2/B 标签分级、ΔM 阈值、CI、种子数）；
- A 级标签可得性审计（A1 数量、来源、许可、与预训练/评价集重叠；A1 不足时预定义降级为半独立任务的判据）；
- 规范与决策记录经同伴评审。

**Phase 1 gate**：可复现基线；冻结 Bacformer vs ANI/PopPUNK 的 A1 级/半独立任务比较；数据审计报告；预训练重叠检查；go/no-go 进入适配。

**Phase 2 gate**：H2a 或 H2b、以及 H3 至少各有一个得到独立来源验证；否则停止或转向评价/数据研究。

**交付物**：`docs/RESEARCH_PLAN.md`、`docs/DATA_GOVERNANCE.md`、`docs/DECISIONS.md`、数据审计报告、基线复现包、评价协议、阶段决策备忘录。

## 9. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| v3 细节未核验/文档不一致 | 复现错误 | 以 v1 PDF + v3 官方仓库/权重为准；逐项记录版本与哈希 |
| 预训练-测试重叠 | 高估泛化 | 按 accession/序列相似度去污染；从全部评价集排除；报告重叠比例与检测限 |
| 近克隆/采样偏倚 | 虚假性能 | Mash/core-SNP/PopPUNK 去重；谱系/来源留出；分层报告；阈值敏感性 |
| 标签循环论证 | 把“复现 ANI”当成增益 | A1/A2/B 标签分级；A1 主结论；B 级 partial Mantel；传统基线分开比较 |
| 注释不一致 | 基因缺失假象 | 统一 Bakta + 原注释对照；质量分层敏感性 |
| 6,000 token 截断 | 丢失质粒/末端基因 | 检查代码；对超限基因组做截断/分块敏感性实验 |
| 算力/存储不足 | 进度受阻 | 先试点；预计算 embedding；按 GPU-hours 规划；20k 臂先做可行性估算 |
| 低风险物种规模不足 | H3/谱系留出失效 | 缩小规模或补充 AllTheBacteria；物种×用途×数据权限作为决策包 |
| 创新性不足 | 论文贡献弱 | 以缺口诊断+独立评价+数据效率组织；不以复现 E. coli 分群为贡献 |
