# StrainFM 菌株表征评价协议草案

## 1 先明确要估计的量

候选主问题：在目标物种内，对来自未参与训练的采样项目、且经过近克隆隔离的基因组，物种适配是否比冻结 Bacformer 提供更好的独立表型预测？它不是对临床可用性或跨物种泛化的检验。

若采用二元表型任务，建议以固定测试集合上的 average precision（AP，阶梯积分定义）为候选主指标。正类含义必须由原标签来源确定；药敏候选任务通常为 resistance=1，但正式使用前仍应核对来源编码。AP 的实现、tie 处理与版本固定，不与梯形 PR-AUC 混称。AUROC、balanced accuracy、Brier score 和校准曲线为辅助；分类阈值只在验证集选取。每次报告有效 N、正负类数量、阳性率、未知/排除记录数。

H2a 的效应量为同一测试集上的 `AP_adapted − AP_frozen`；H2b 为 `AP_adapted − AP_best_traditional`，传统基线依据验证集选择。二者分开报告。若有多个药物，先选一个确认性主任务，其他任务为探索性或按预定方法校正，不能在测试后挑选最显著者。

若最终用途不是表型预测，则需在测试前另行接受对应的主任务；不能直接把本草案的 AP 当作已决定指标。

## 2 数据身份和标签规则

每条记录至少保留：`original_genome_id`、实际带版本的 assembly accession、paired accession、BioSample、BioProject、来源研究、采集时间及精度、组装质量、注释版本、FASTA SHA-256、谱系/近克隆簇和预训练暴露状态。

精确重复组装、同一 BioSample 的多个组装/数据库副本不能跨集合。GCA/GCF 配对以官方元数据和文件版本为准。缺失值显式保留 unknown；不能把无药敏标签当作敏感，也不能把缺失年份当作最早年份。

标签审计分两个轴：

| 轴 | 值 | 解释 |
|---|---|---|
| 标签来源 | 独立实验表型、独立采样/流行病学证据、来源元数据、序列派生标签 | 暴发标签若主要由 SNP 阈值定义，仍不能当作独立于序列的金标准 |
| 暴露状态 | 已知重叠、检索范围内未发现重叠、无法核验 | “未发现”要说明检查范围；不是绝对干净证明 |

AST 标签需核验测定方法、解释标准及版本、S/I/R 或 MIC 规则、重复测定冲突。已有汇总表缺少这些字段时先标为候选标签，不能假定所有来源可直接合并。其他论文/PATRIC/NCBI AST 的样本交集仍需按 BioSample/accession 检查，换下载网址不是独立来源。

## 3 划分和防泄漏

1. 建立精确身份组和近克隆组；保留阈值敏感性，不把 PopPUNK 的种内谱系簇直接等同于唯一的克隆阈值。
2. 主评价优先留出来源研究/BioProject，并将同一近克隆组整体放在一侧。来源与克隆组交叉时，可以构建二者关系的连通分量；若出现巨大分量导致无法划分，报告不可行，不能随机拆开来保证比例。
3. 谱系留出作为另一种分布偏移分析；“来源留出”不自动意味着“谱系留出”，每个 split 报告实际交集。
4. 仅用训练组拟合特征筛选、标准化、监督头和适配；验证组用于模型选择。最终测试组不得参与继续预训练，即使没有使用其标签。
5. 若使用全体未标注序列建立去重簇以防泄漏，记录这一用途。Panaroo 家族词表或其他由评价序列共同构建的特征空间，应明确是 transductive 设置；严格 inductive 比较需在训练集定义词表并处理测试集新家族。
6. 预训练重叠检查覆盖整个评价池；无法核验者另分层报告。基础蛋白模型的语料暴露与 Bacformer 基因组语料暴露分别说明。
7. 保存实际 split manifest、输入哈希和随机种子。必须断言精确 ID、BioSample、指定排斥组之间无泄漏，并检查每个评价集合的类别支持。失败则停止；禁止回退到随机划分。

没有必要为达到某个固定 80/10/10 比例破坏分组约束。若独立组过少，应降低结论强度或补充数据，不把基因组数量当作独立组数量。

## 4 基线及可归因比较

| 对照 | 作用 | 公平性要求 |
|---|---|---|
| 常数/阳性率预测与来源字段简单模型 | 检查指标底线和明显来源混杂 | 来源模型只能使用部署时真正可用字段；同时可作纯诊断 |
| k-mer 特征加线性模型 | DNA 内容基线 | 只在训练集拟合词表/筛选；固定资源与调参预算 |
| 基因家族 presence/absence 加线性模型 | 可变基因组内容基线 | 固定注释、家族定义、缺失与未知家族处理 |
| ESM-2 35M 均值与 Bacformer Base | 上下文增量 | 完全相同蛋白序列、编码器、保留蛋白集合和 pooling |
| ESM-C small 均值与 Bacformer Large | 上下文增量 | 同上；不能只拿 ESM-2 均值作 Large 的归因对照 |
| 冻结与一个适配版本 | H2a | 相同样本、输入、监督头、调参次数及测试集 |
| ANI/Mash/core-SNP/cgMLST/PopPUNK | 遗传距离/谱系诊断 | 距离不是天然的表型分类器；若用于预测，需给定固定 kNN/核方法及相同验证预算 |

不要求第一轮把所有距离方法都跑一遍。优先一个可扩展的 DNA 距离对照、一个基因家族对照和匹配的蛋白基线；近缘分辨率有疑问时再补 core-SNP/cgMLST。选择比较对象取决于它能排除哪种解释。

## 5 输入和模型正确性检查

- 固定 checkpoint revision、蛋白编码器 revision、软件环境、注释版本、dtype、蛋白 pooling、基因组 pooling、最长蛋白与最长基因组参数。
- 建立不加载大权重的输入张量测试，检查 Base CLS/SEP/END、contig ID 边界、排序恢复、截断前后长度。第三方源码当前 SEP 默认值异常须先处理。
- 保留每个样本的输入蛋白数、保留数、截断 fraction，以及实际受影响的 contig/replicon；单蛋白残基截断与全基因组蛋白截断分别记录。
- 推理关闭 dropout，固定模式与随机性，重复同一输入验证稳定性；校验特殊 token 和 padding 不进入错误的 pooling。
- 完整环状染色体做起点变化、contig 顺序变化等输入表示稳健性对照；draft contig 顺序变动不是已知生物学重排。
- “打乱顺序”仅检验模型对顺序的依赖，不能单独证明学到了功能因果关系。自然样本的 synteny/内容对照与人为输入扰动分开报告。
- 若继续原 MPFP，先核验原始蛋白簇词表、ID 映射和新蛋白覆盖；无法恢复时不要把重定义任务称作原目标的直接延续。

## 6 检索任务的精确定义

评价若包含检索，必须公布 query 集 Q、候选库 G、正例定义 R(q)、去自身规则、重复/近克隆排除规则，以及各谱系的 query 与 gallery 数量。

- 已见谱系检索：训练可见谱系，查询为未见样本，排除同一 BioSample/重复组装。它不是未见谱系泛化。
- 未见谱系检索：适配训练中排除这些谱系，随后在 held-out 谱系中建立独立 query/gallery，保证每个计分 query 有 gallery 正例。gallery 不参与训练或超参选择。
- 谱系是正例标签时，结果属于序列派生标签诊断；若用独立表型/流行病学标签，另述定义与不确定性。

候选 `k={1,5,10}`，需在看测试结果前冻结。对 `|R(q)|>0` 的 query：`Recall@k(q)=|top_k(q) ∩ R(q)|/|R(q)|`，先对 query 求均值，再单独报告谱系宏平均；分母不能改成 k。`Hit@k=1[至少一个正例进入 top_k]` 是另一指标，不得也称 Recall@k。无正例 query 不设为零混入平均：单独报告数量和占比。候选库小于 k 时用 `min(k, |G|)`，报告实际候选规模；并报告簇大小与距离 ties 的敏感性。

## 7 统计、效应量和功效

候选重复种子为 3 个固定种子，仅作为资源允许下的起点；种子不等于独立生物重复。预设同一测试面板上各模型的配对比较，使用相同的组级重采样索引；建议 2,000 次 bootstrap，报告区间、组数、组大小和重复间变异。具体组单位应与采样设计匹配；谱系与来源交叉时不能随意二选一。小于足够独立组数时，bootstrap 次数再多也不能弥补设计不足。

pairwise 距离数量为 `n(n−1)/2` 不表示有那么多独立样本；置换必须满足零假设下的交换性。默认不对展平距离矩阵使用独立样本相关性 p 值，也不将 partial Mantel 作为去混杂证明。

最低实用差异 `δ` 由研究用途确定，并在测试前接受。尚无依据设定唯一数值；可在独立开发数据上针对 AP 绝对差 0.02/0.05/0.10 做组级模拟，估计在当前类别比例和组结构下能否排除小于 δ 的收益。这些值是功效分析场景，不是已经生效的成功门槛。

建议区分：

- 区间下界 > δ：支持超过最低实用增益；
- 下界 > 0 但跨 δ：有正向证据，实用增益仍未确定；
- 区间覆盖 0 且上界 ≥ δ：证据不足，不能断言无收益；
- 区间上界 < δ：不支持达到预设实用收益；是否停止还取决于预先约定的预算与诊断完成情况。

主任务外的多重比较使用预定的 Holm 等方法，或明确标为探索性；不混用两种报告方式选择有利结论。

## 8 数量与多样性实验

在适配有可解释信号后，才开展 H3。可从三个规模点开始，例如 250/1000/2000 个训练基因组；它们是草案场景，最终数值取决于去重后训练池与实际预算。大样本臂嵌套小样本臂，配对随机种子，固定独立验证和测试面板。

随机臂与多样性臂使用同一可用训练池。多样性先明确为“固定基因组数量下覆盖更多训练集谱系簇”，质量、长度和来源分布要记录；若无法同时匹配所有条件，报告剩余不平衡。抽样不能利用测试标签或测试嵌入距离。应区分训练数据采样种子与模型优化种子。

主比较可固定已处理蛋白 token 预算，另报实际 GPU-hours；同时记录 epochs/重复暴露。不要把等数据量、等步数和等算力混为一谈。从零模型若只匹配本项目适配预算，结论只涉及增量预算下的效果，不能宣称总训练成本公平。

正式实验前需完成并冻结：目标物种和用途、数据权限、主任务和正类、独立标签来源、实际训练/验证/测试 ID、近克隆与来源组、预训练重叠状态、主指标及 δ、功效/精度可行性、模型与代码 revision、随机种子、资源预算、失败/停止规则。

这些条件当前尚未全部满足。本轮完成的是数据与方法可行性证据，下一项可交付工作是**指定候选物种的标签子集身份、来源和去重审计，以及输入转换正确性验证**；不需要先训练模型来判断这些条件。
