### 2.1 确定性抽样质检

每个物种按 `SHA256("20261104\t" + genome_id)` 排序，取前 25 个映射记录，在检查存在性之前选样，不用正常文件替补失败样本。100/100 个文件通过 gzip 完整读取及 DNA IUPAC 格式校验；样本内未发现相同序列记录多重集合哈希。此哈希忽略 FASTA header、大小写、换行和记录排列，但不消除反向互补、环状起点或不同组装断点；它不是近克隆去重。

原始 FASTA 计算的是**记录长度 N50**，记录可能是 scaffold，不能直接套用 contig 阈值。下载记录中 `max_contig_bases` 和 `contig_multiset_sha256` 这两个审计字段同样以 FASTA 记录为单位；解释以结果 README 为准。未检验污染、完整度、物种身份、质粒归属或统一注释，因此没有赋予 A/B/C 质量层。每种仅 25 个样本，不外推完整基因组比例为全物种精确比例。

### 4.2 影响实验有效性的具体风险

1. **编码器必须匹配。** 官方 Base 使用 ESM-2 `esm2_t12_35M_UR50D`，Large 使用 ESM-C 的 `Synthyra/ESMplusplus_small` 实现。Large 与 ESM-2 均值的差异同时混入了蛋白编码器变化；要归因于上下文，必须增加匹配的 ESM-C 均值基线。Base 与 Large 的比较也不是单一“模型规模消融”。[官方 README](https://github.com/macwiatrak/Bacformer/blob/61dca9537429b95365d73d72a3e11c207df1ed6c/README.md)

2. **6000 与 9000 的差异已定位到代码。** BacBench 输入转换默认参数为 9000，而 genome embedding 函数默认 6000，示例显式传 9000；Large checkpoint 配置为 6000。Large 输入按拼接后的前 N 个蛋白截断；Base 则把 CLS、分隔符和 END 计入序列预算。6000 对两类模型不是完全相同的蛋白覆盖率。Large 使用旋转位置编码，配置 6000 不应被误写成“9000 必然报错”；超长能否稳定工作必须单独验证，不能默认等价。[输入转换 L128–211](https://github.com/macwiatrak/BacBench/blob/64b7d45823b2ff2ef88458e3aa235caa461a12aa/bacbench/modeling/utils/utils.py#L128)

3. **Base 分隔 token 默认值异常。** 上述函数 L135 将 `sep_token_id` 默认设置为 `BACFORMER_SPECIAL_TOKENS_DICT["CLS"]`；同文件字典中 CLS=2、SEP=3。当前 embedding 调用未覆写该参数。静态代码已确认不一致，但本轮未执行模型，不能量化其影响。正式基线需要先做输入张量测试并固定修正版本。[调用 L177–183](https://github.com/macwiatrak/BacBench/blob/64b7d45823b2ff2ef88458e3aa235caa461a12aa/bacbench/modeling/embed_prot_seqs.py#L177)

4. **分组划分失败会回退到样本随机划分。** 药敏评价 `_split_indices` 在 group split 抛异常时直接调用 `_fallback_shuffle()`。这样可能使一次本应失败的来源/谱系留出返回有效指标。项目正式入口需要失败即停止，并对实际 train/val/test 集合做交集断言；仅保存 `split` 参数不足以证明执行了指定划分。[评价实现 L131–146](https://github.com/macwiatrak/BacBench/blob/64b7d45823b2ff2ef88458e3aa235caa461a12aa/bacbench/tasks/antibiotic_resistance/train_and_predict_linear.py#L131)

5. **不能把旧 strain clustering 当作标准主任务。** BacBench README 明确说明该任务已 deprecated，仅为复现保留。其存在不证明划分适合本研究。[BacBench 状态](https://github.com/macwiatrak/BacBench/blob/64b7d45823b2ff2ef88458e3aa235caa461a12aa/README.md#news)

6. **继续 MPFP 还缺目标词表映射核验。** Large 配置包含 50,001 类输出，代码用蛋白簇 ID 作分类标签。若要保留原头继续训练，必须能复用同一簇定义和 ID 映射，并报告新蛋白的覆盖率；任意重聚类后沿用原头没有一致的标签语义。本轮未验证该映射资源是否完备，不能写成已具备继续预训练条件。[模型头](https://github.com/macwiatrak/Bacformer/blob/61dca9537429b95365d73d72a3e11c207df1ed6c/bacformer/modeling/modeling_large.py#L985)

**截断已有本地风险证据。** P. aeruginosa 样本中 16/25 个 accession 提供蛋白编码基因数，其中 10/16 大于 6000；另 9 个未知。它是原注释计数，不是统一注释后输入 token 实测值。E. coli 和 K. pneumoniae 各有 20/25 个已知计数，已知者均不超过 6000，但 Base 的特殊 token 和单蛋白长度限制仍须另查。[元数据逐项表](../data/results/ncbi_sample_metadata_20261104/sample_metadata.tsv)

## 5 应把信息缺失与学习不足分开

令 `X(g)` 为预处理后真正送入模型的有序蛋白 embedding 与 contig 信息，`z(g)=Fθ(X(g))` 为确定性推理结果。如果两个基因组 `X(g1)=X(g2)`，那么对任意参数 θ 都有 `z(g1)=z(g2)`。这是模型输入的逻辑边界，不是本项目已观察到的菌株分布结果。

因此，纯蛋白上下文输入不能**直接**区分那些没有改变翻译序列、蛋白顺序或其他输入字段的同义/非编码差异。它可能借助连锁蛋白变异间接预测相关表型，但这不等于读到了那些 DNA 位点。只以 DNA core-SNP 最近邻为目标证明蛋白模型“差”，可能检验的是模态缺失，而不是可由继续预训练修复的能力缺口。

应拆成三个可证伪层次：

| 层次 | 需要的证据 | 如果失败，改变什么判断 |
|---|---|---|
| 输入保真度 | DNA/蛋白一致性、被截断蛋白比例、注释差异、确定性推理重复性 | 修输入或限定任务；不先增加训练 |
| 上下文增益 | Bacformer 对比同一蛋白编码器均值、基因家族特征；按自然变异类型分层 | 若均值或家族内容已足够，则缺乏额外上下文收益证据 |
| 可迁移的适配增益 | 冻结与适配在同一外部标签、同一来源留出上的配对差异 | 若只提升同源数据或 B 级标签，不声称生物学外推 |

一组有信息量的诊断应包含：核心近/可变远、可变近/核心远、两者均近，以及输入完全相同但 DNA 不同的自然对照。前三类配对由序列方法定义，所以只能支持信息保留的诊断；不能凭这些构造标签取代独立表型证据。

同样需要区分“mean pooling 稀释少数差异”与“编码器没有保留差异”。在非上下文化均值中，单个 token 的变化对均值按蛋白数量缩小；Bacformer 的变化可传播到其他 token，不能直接用这个比例预测它的性能。只有比较基因组 pooling、匹配蛋白差异和任务表现，才能决定是否值得换聚合方式。

## 6 评价设计需要修正的六个要点

**第一，标签独立性和预训练暴露是两个轴。** AST 表型并非由当前 embedding 构造，因而可以是 A1 候选；若同一基因组已经被基础模型看过，它仍不是干净的未见基因组外推。每个样本应分别记录标签来源和预训练重叠状态，不能以 A1 替代去污染检查。

**第二，partial Mantel 不是去混杂保证。** Guillot 与 Rousset 的研究表明，当比较量在零假设下均有自相关结构时，partial Mantel 的显著性仍可能偏误。不能把“控制来源距离矩阵”写成已经去除了谱系/批次混杂。优先通过分组留出、组内匹配、独立测试和合法的组级重采样处理问题；距离相关性留作描述，不对所有样本对当独立观测做显著性检验。[原研究](https://arxiv.org/abs/1112.0651v2)

**第三，谱系留出和检索正例定义必须相容。** 若测试谱系完全不在训练参考库中，以“同谱系”为正例的检索没有正例。可把评价分成已见谱系中的未见样本检索，以及未见谱系内独立 query/gallery 检索；后者的 gallery 属于评价环境，不参与适配。两者回答不同问题，不能混合报告一个 Recall@k。

**第四，随机划分与来源留出的指标差不是自动等于泄漏量。** 测试组成、类别比例、质量和难度同时变化时，差值还包含分布偏移。若要量化训练邻近性带来的乐观效应，应尽量固定测试面板，控制训练样本量与来源支持，再比较保留/移除近缘训练样本的条件；否则准确命名为“划分协议差异”。

**第五，不把“不显著”写成“无差异”。** 适配相对冻结模型 H2a、相对传统基线 H2b 分别估计。置信区间覆盖零只说明证据不足；只有区间也排除预设的最小实用增益，才支持“未达到目标收益”。是否支持 H1 不应成为 H2 的逻辑先决条件，反之冻结模型差也不自动说明值得适配。

**第六，多样性效应须排除训练预算与标签分布差异。** 固定数量的多样性采样与随机采样应来自同一训练池，匹配质量与长度，记录训练 token 数、步数、重复暴露与实际 GPU-hours；不能同时声称不同长度样本严格满足等步数、等 token 和等运行时间。标签丰富度、国家、测序项目和谱系不是同一个“多样性”概念。预先选一个可操作定义，再观察其他维度。

Yu 等在五种细菌的实验表型数据上构造采样偏倚条件，发现增加样本数未必能消除群体结构带来的预测问题。这支持本项目优先检验样本组成的动机，**没有证明本项目的多样性采样一定优于随机采样**。[PLOS Biology 原研究](https://doi.org/10.1371/journal.pbio.3003539)

## 7 创新空间和实验优先级

当前已有 Bacformer、同编码器蛋白均值、泛基因组特征与 DNA/混合输入路线。gLM2 也已公开将蛋白编码区的氨基酸 token 与间隔区 DNA token 联合建模；其 token 单位与 Bacformer 的“一个蛋白一个 token”不同，不能拿相同 token 数宣称相同基因组覆盖。[gLM2 官方实现](https://github.com/tattabio/gLM2)

因此，不宜把“蛋白上下文”“加入 DNA”或“单物种训练”本身写成已经成立的新颖性。更可辩护的贡献候选是：

1. 明确哪些菌株差异在预处理时丢失，哪些在蛋白编码、上下文化或 pooling 中减弱，并给出能复现的反例和分层诊断。
2. 在测量来源可追溯、去重与来源留出成立的同一任务上，量化物种适配增加的实用收益与代价。
3. 在同一训练池与固定资源约束下，把新增数量和新增谱系覆盖的作用区分开。

这不是对全领域新颖性的保证。v3 全文、未公开训练清单与相关工作的完整消融尚未核验；正式投稿前需要补足。

建议依次开展，具体划分与指标见[评价协议](STRAIN_EVALUATION_PROTOCOL_DRAFT.md)：

| 次序 | 具体产物 | 能改变的判断 | 开始条件 |
|---|---|---|---|
| 1 | 标签候选集的 accession/BioSample/BioProject/实验条件/近克隆和预训练暴露表 | 是否能形成足够独立的测试集 | 用户确认物种、用途、允许数据范围 |
| 2 | 约 200 个候选基因组的统一注释与输入覆盖审计，保留失败项 | 截断、注释或模态缺失是否主导 | 数据权限与存储明确；数量为提议 |
| 3 | 同编码器均值、冻结 Bacformer、k-mer/家族特征基线，受限调参 | 上下文是否增加任务信息 | 评价集合和主任务冻结 |
| 4 | 单一适配方案与冻结表示的配对比较 | H2a 是否值得进一步投入 | 基线正确、预训练目标映射可复现、预算明确 |
| 5 | 三个规模点的随机/多样性采样比较 | 数量和覆盖的相对作用 | 独立评价精度足够且适配有信号 |

先在 32 个、再在 128 个符合条件的基因组上测资源吞吐是工程基准，不属于科研性能结论。不要同时铺开多种架构、20k 全学习曲线、全部物种和全部药物。

## 8 资源估计与停止条件

本轮 `nvidia-smi` 确认 1 张 RTX 5090 D，32,607 MiB 总显存；项目所在文件系统约有 452G 可用，E 盘约有 972G 可用，均为瞬时快照。Bakta、GTDB-Tk、CheckM2、PopPUNK、chewBBACA、Mash、FastANI、Prodigal 在当前 PATH 不可用；这不等于所有其他环境均未安装。没有安装大型环境或下载权重。

缓存应按对象而非沿用旧论文总存储数字估计。例如**假设**每个基因组平均 4,500 个蛋白、保存一个 960 维 BF16 向量/蛋白，则 `N × 4500 × 960 × 2` 字节：

| 基因组数 | 单层逐蛋白缓存的理想字节体积 |
|---:|---:|
| 1,000 | 8.64 GB |
| 5,000 | 43.2 GB |
| 62,560 | 540.5 GB |

这是十进制 GB，不含索引、注释、重复层、checkpoint 和数据库；FP32 翻倍，480 维减半。若仅保存每基因组一个 960 维 BF16 向量，62,560 个约为 120 MB，但不能据此恢复逐蛋白特征以继续训练。精确相同蛋白可按序列哈希复用冻结编码器缓存，实际节省率须测量。

不同硬件的 GPU-hours 不可直接线性换算为本机墙钟；旧计划从 Ponte Vecchio 推算的时间不是 RTX 5090 D 实测。资源基准须分别记录注释、蛋白编码、上下文化、适配和评价成本，并说明是否含一次性预处理。

建议的停止/转向依据：

- 独立测试组或类别支持不足：保留描述性输入诊断，不作适配成功/失败的确认性结论。
- 无法确定预训练重叠：按 overlap unknown 单独报告，限制“未见基因组”主张；不假定干净。
- 差异主要不在蛋白输入中：缩小任务范围或提出 DNA 对照，不能无限继续蛋白预训练。
- 同编码器均值已达到实用目标且上下文没有可辨别收益：优先保留简单方案，结果可作为负面证据。
- 适配的配对区间上界低于已接受的最小实用增益，且达到预设计算上限：停止该适配路线。
- 输入错误、截断或分组回退尚未排除：先修正确性问题，不解释模型指标。
