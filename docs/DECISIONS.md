# StrainFM 决策记录

本文件记录影响研究目标、数据范围、评价标准与发布的决定。每条包含日期、负责人、证据、影响和状态。状态：`proposed`（提议）、`active`（生效）、`pending`（待定）、`superseded`（被取代）。

## 决策流程

- 用户/导师对目标物种、用途、数据权限、资源和最终验收有决定权。
- 项目负责人提出研究/技术决策，记录证据与影响；协作者可评审，但不能以共识代替用户授权。
- 实质改变研究问题、数据范围、主指标、训练规模或对外发布，必须新增/更新本文件。
- 可逆的日常工作自主推进；不可逆、共享状态、新增费用或敏感数据外传先取得决定。

## 待决事项

1. **目标物种**：导师是否已指定？E. coli、K. pneumoniae、P. aeruginosa，还是其他？
2. **研究用途**：菌株分型/暴发溯源、生态/宿主关联、AMR 表型、方法学 benchmark，还是其他？
3. **数据权限**：FASTA 路径如何访问？临床数据是否需要数据使用协议？可用物种范围？
4. **算力与存储**：GPU 型号/数量、可用存储、可接受训练规模；embedding 预计算与缓存策略。
5. **主指标**：独立来源留出集上的 Recall@k、AUPRC，还是其他？k 集合、ΔM 阈值、CI 与种子数如何预设？
6. **版本管理**：已决（D0-13）：公开仓库 `main` 单线开发；数据/权重不入库，小型正式结果选择性提交。
7. **产出目标**：论文、工具、内部报告或数据集；时间线与投稿目标。
8. **发布政策**：适配权重/嵌入默认不发布；发布需谁批准、在什么范围内发布？
